🎯 O QUE É?

DOIT quebra objetivos complexos em roadmaps operativos:

    Objetivo: "Vender meu produto para 100 pessoas"

    ↓ OpenRouter (Claude) quebra em:

    FASE 1: Setup (3 passos)
    ├─ Passo 1: [HUMANO] Validar 10 ICPs
    │           [MÁQUINA] Extrair via Phantombuster
    ├─ Passo 2: [HUMANO] Revisar email
    │           [MÁQUINA] Enriquecer com Hunter.io
    └─ Passo 3: [HUMANO] Aprovar sequência
                [MÁQUINA] Agendar via Instantly.ai

    ↓ Kanban interativo

    User marca passos como "Finalizado (Humano)" ou "Finalizado (Máquina)"

    ↓ GRATIDÃO registra tudo

    Evento: passo_humano ✓
    Evento: passo_maquina ✓
    Quando completo → Evento: validacao_completa (projeto vira "1")

📊 INTEGRAÇÃO GRATIDÃO

Cada projeto DOIT = Lei da Fábrica (0 → 1 Validação):

    CRIAÇÃO
    ├─ evento_tipo: "criacao"
    └─ status: "ideacao" (0)

    CADA PASSO
    ├─ evento_tipo: "passo_humano" | "passo_maquina"
    └─ metadata: { descricao, quem_resolveu }

    CONCLUSÃO
    ├─ evento_tipo: "validacao_completa"
    └─ status: "validado" (1)
    ├─ metadata: { passos_totais, humano, maquina }

TABELA: doit_gratidao_eventos
└─ Permite queries:
   ├─ Taxa conversão (0→1)
   ├─ Ratio humano/máquina
   ├─ LLM mais eficaz
   └─ Tempo médio projeto
