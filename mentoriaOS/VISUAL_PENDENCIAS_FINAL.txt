   - Texto: red-400
   - Ícone: red-400

   - from-slate-700/40 to-slate-800/40
   - border: slate-600/30
   - hover: slate-600/40

INTERAÇÕES:

1️⃣  Criar Tarefa:
    • User digita no input "Nova tarefa..."
    • User seleciona data (opcional)
    • User clica "+ Adicionar"
    • ✅ Tarefa aparece em <100ms no topo da lista
    • 📊 Badge contador aumenta de 2 para 3

2️⃣  Marcar Completa:
    • User clica checkbox ☐
    • ✅ Checkbox fica ☑ (verde)
    • Tarefa some da seção "Pendências"
    • 📊 Badge diminui de 3 para 2
    • Tarefa aparece em "Completadas Hoje" com strikethrough
    • Mostra: "✓ Concluída em HH:MM"

3️⃣  Deletar:
    • User hover na tarefa → aparece 🗑️ (vermelho)
    • User clica 🗑️
    • Confirmação: "Tem certeza que deseja deletar?"
    • ✅ Tarefa desaparece imediatamente
    • 📊 Badge e contadores atualizam

4️⃣  Trocar Mentorado:
    • User clica em mentorado diferente na sidebar
    • ⚡ Seção "Pendências" recarrega em <1s
    • Mostra tarefas do novo mentorado
    • Completadas Hoje reseta (tarefas do dia anterior)

═══════════════════════════════════════════════════════════════════════════════

LAYOUT RESPONSIVO:

📱 MOBILE (< 768px):
   • Sidebar colapsável (ícone hambúrguer)
   • Cards em stack vertical (100% width)
   • Input + data picker em coluna
   • Botão "+ Adicionar" ocupa full-width

💻 DESKTOP (≥ 768px):
   • Sidebar sempre aberta
   • Cards em layout horizontal otimizado
   • Input + date picker + botão em linha
   • Hover effects (lixeira) aparecem

VALIDAÇÕES:

✅ Texto não pode ser vazio
✅ Data vencimento é opcional
✅ Se data passada, marca "Vencida" em vermelho
✅ Se data hoje, marca "Hoje"
✅ Se data amanhã, marca "Amanhã"
✅ Checkbox só aparece se mentorado selecionado
✅ Sem tarefas mostra: "Nenhuma pendência! 🎉"
