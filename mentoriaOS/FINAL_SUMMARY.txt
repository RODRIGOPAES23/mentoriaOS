✨ mentoriaOS é um sistema de mentoria inteligente que:

1. Centraliza dados de mentorados (12 meses)
2. Coleta checkins semanais (vendas, leads, vídeos)
3. Analisa com Claude IA
4. Gera pautas estruturadas para calls
5. Acumula histórico (zero contexto perdido)
6. Tudo em um dashboard limpo e moderno

📊 Stack: Next.js + React + Supabase + Claude + Vercel
🎯 Status: Pronto para produção
⚡ Performance: Otimizado e escalável
🔐 Segurança: RLS + JWT + HTTPS
